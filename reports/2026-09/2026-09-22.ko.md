### 1. DoinGud — 해킹/익스플로잇

- **원문**: [DoinGud — Smart Contract Vulnerability](https://x.com/teddyctf/status/2102235278970933264) (SlowMist Hacked, 2026-09-21)
- **사건일**: 2026-09-21  |  **체인**: Polygon  |  **금액**: $35.5K
- **태그**: Smart Contract Vulnerability

**사건 배경**  
DoinGud는 한때 운영됐던 NFT 플랫폼으로 현재는 휴면 상태였습니다. 이 플랫폼은 Polygon 체인 위에 Diamond 입찰 계약을 사용했습니다. 계약의 acceptBid 함수가 입찰 기록을 삭제하지 않아 동일 입찰을 재사용할 수 있었습니다.

**공격/범죄 수법**  
공격자는 계약 잔액만큼 USDC를 플래시론으로 빌려 자신에게 입찰하고, acceptBid을 두 번 호출해 동일 입찰을 재사용해 자금을 인출했습니다.

**요약**  
2026년 9월 21일 DoinGud의 Diamond 입찰 계약에 버그가 악용돼 $35,486 규모의 USDC가 탈취되었습니다. 공격자는 플래시론을 이용해 입찰을 두 번 승인했습니다. 현재 복구나 추가 조치는 보고되지 않았습니다.

**자금 흐름**  
플래시론 USDC → 공격자 입찰 → acceptBid 두 번 실행 → $35,486 USDC 인출.

### 2. GaslessReservoirEnabler — 해킹/익스플로잇

- **원문**: [GaslessReservoirEnabler — Smart Contract Vulnerability](https://x.com/SlowMist_Team/status/2102227043979313539) (SlowMist Hacked, 2026-09-21)
- **사건일**: 2026-09-21  |  **체인**: Polygon  |  **금액**: $23.0K
- **태그**: Smart Contract Vulnerability

**사건 배경**  
GaslessReservoirEnabler는 Polygon 위에 배포된 스마트 계약으로, 토큰 전송과 실행을 결합하는 기능을 제공한다. 이 계약은 모듈 주소를 검증하지만 ERC-20 transferFrom 호출을 자산 소유자와 연결하지 않는 결함이 있었다. 공격자는 이 허점을 이용해 허가된 토큰(WETH, ZED)의 기존 allowance를 소진할 수 있었다.

**공격/범죄 수법**  
권한 결함으로, erc20WithTransfersAndExecute → _executeInternal 함수가 모듈 주소만 확인하고 transferFrom 호출을 인증하지 않아 공격자가 피해자의 allowance를 무단 사용했다.

**요약**  
2026년 9월 21일, 공격자는 GaslessReservoirEnabler 계약의 허점을 이용해 약 997명의 토큰 보유자에게서 총 $23,000을 탈취했다. 탈취된 자금은 Polygon 브리지로 통합되어 이동되었다. 피해액은 비교적 작지만, 허가된 토큰의 allowance 남용 위험을 보여준다. SlowMist은 해당 취약점을 공개하고 교정을 권고했다. 현재 계약은 패치가 진행 중이다.

**자금 흐름**  
탈취된 $23,000은 Polygon 브리지로 입금되어 다른 체인으로 이동될 가능성이 있다.

### 4. Internet Token — 해킹/익스플로잇

- **원문**: [Internet Token — Smart Contract Vulnerability](https://x.com/DefimonAlerts/status/2101969009461567690) (SlowMist Hacked, 2026-09-21)
- **사건일**: 2026-09-21  |  **체인**: Base  |  **금액**: $265.0K
- **태그**: Access Control, Arbitrary External Call, Smart Contract Vulnerability
- **다른 출처**: [DeFiLlama Hacks](https://defillama.com/hacks)

**사건 배경**  
Internet Token DAO는 Base 체인에 INT/WETH 풀을 운영한다. LiquidityUnifier 계약은 외부에서 제공된 Uniswap V3 풀 주소를 신뢰하도록 설계되었다. 이 설계 결함이 공격자가 가짜 풀을 등록하게 만들었다.

**공격/범죄 수법**  
공격자는 호출자 제공 풀 주소를 이용해 가짜 Uniswap V3 풀 콜백을 실행했다. 가짜 풀은 약 9억 2500만 INT를 무에서 생성했다. 이후 공식 INT/WETH 풀에서 5.847 WETH를 인출하고 7억 6400만 INT를 보유했다.

**요약**  
2026년 9월 21일, 공격자는 LiquidityUnifier의 취약점을 이용해 $265,000 상당의 자금을 탈취했다. 가짜 풀 콜백으로 대량의 INT를 발행하고, 공식 풀에서 WETH를 빼냈다. 공격자는 보유한 INT를 이용해 거버넌스 제안을 제출해 금고 자금 이동을 시도하고 있다. 현재 계약의 mint 권한은 아직 회수되지 않았으며, 유사 공격이 추가로 발생하고 있다.

**자금 흐름**  
가짜 풀 콜백 → 925M INT 민팅 → 공식 INT/WETH 풀에서 5.847 WETH 인출 → 764M INT 보유.

### 5. RWC Token — 해킹/익스플로잇

- **원문**: [RWC Token — Smart Contract Vulnerability](https://x.com/TenArmorAlert/status/2101925758214316524) (SlowMist Hacked, 2026-09-21)
- **사건일**: 2026-09-21  |  **체인**: BNB Smart Chain  |  **금액**: $109.5K
- **태그**: Smart Contract Vulnerability

**사건 배경**  
RWC Token은 BNB Smart Chain 위에 배포된 ERC-20 호환 토큰이다. PancakeSwap에 RWC/USDT 유동성 풀을 제공하고, 토큰 전송 시 일정 비율을 프로젝트 회사와 플랫폼 지갑으로 보내는 수수료 로직을 갖고 있다. 풀의 스마트컨트랙트에 보호되지 않은 burn 함수가 있어 외부에서 호출할 수 있었다. 공격자는 플래시론을 이용해 이 함수를 악용했다.

**공격/범죄 수법**  
플래시론을 이용해 PancakeSwap RWC/USDT 풀의 RWC를 소각하고, sync()를 호출해 풀의 잔액을 재조정해 가격을 인위적으로 상승시킨 뒤 USDT로 판매했다.

**요약**  
2026년 9월 21일, 공격자는 플래시론으로 풀을 조작해 약 $109,460.85 상당의 USDT를 탈취했다. 탈취된 금액 중 $39,964.07은 공격자 지갑에 남았고, 나머지 $69,496.78은 토큰 수수료 로직에 따라 프로젝트 회사와 플랫폼 지갑으로 전송되었다. 피해 풀은 PancakeSwap RWC/USDT 페어이며, 손실은 한 트랜잭션으로 발생했다.

**자금 흐름**  
탈취된 USDT 중 $39,964.07은 공격자 지갑으로, $69,496.78은 토큰 수수료 로직에 따라 프로젝트 회사와 플랫폼 지갑으로 전송되었다.
